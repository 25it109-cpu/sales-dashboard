# sales-dashboard
# 📊 Sales & Revenue Dashboard

An interactive web-based dashboard to analyze sales and revenue data — built with HTML, CSS, and JavaScript (no frameworks required).

---

## 🚀 Live Demo

> Open `index.html` in any browser — no installation needed.

---

## ✨ Features

| Feature | Details |
|---|---|
| 📥 **Data Import** | Upload CSV, Excel (.xlsx/.xls), or JSON files |
| 📊 **KPI Cards** | Total revenue, orders, avg order value, return rate |
| 📈 **Revenue Trend** | Monthly bar chart — current year vs previous year |
| 🍩 **Category Breakdown** | Donut chart by product category |
| 🏆 **Top Products** | Ranked table with revenue bars |
| 🔍 **Filters & Slicers** | Year selector, quarter filter, category slicer |
| 💾 **Export** | Download filtered data as CSV |

## 🔧 Technologies Used

- **HTML5 / CSS3 / Vanilla JavaScript** — zero build tools
- **Chart.js 4** — revenue & category charts
- **PapaParse** — CSV parsing
- **SheetJS (xlsx)** — Excel file reading
